# Engineering Case Challenge 2: A unified search and AI experience

## Problem statement

> We currently use Elasticsearch to power site search. While functional, search relevance and ranking need improvement to help users quickly find the most valuable content. Additionally, we want to integrate the AI Assistant so that users can see both search results and direct answers to their queries in one unified experience.

> Explain how you would build it. Discuss:
> - Search Experience: How you would enhance ranking (specialty, drug, KOL, conference, recency) and add personalization to improve usability.
> - AI Integration: How you would integrate AI Assistant responses into search results, ensuring citations and deep links back to content.
> - Implementation Strategy: How you would evolve the current search system with minimal downtime and balance engineering effort with business value.
