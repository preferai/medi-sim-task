# Engineering Case Challenge 1: A research-informed solution

## Problem statement

> We are interested in a large volume of new content from conferences, institutions, and KOLs.
> Today, metadata such as title, specialty, sub-specialty, drug mentions, and KOL affiliation is often inconsistent and requires manual work. To improve search, recommendations, and user trust, we want to build an automated content classification pipeline leveraging Generative AI.
>
> Explain how you would build it. Discuss:
> - Technical Architecture: How you would design the pipeline for content ingestion, preprocessing, AI inference, human-in-the-loop validation, and structured metadata storage.
> - Evaluation & Monitoring: Which metrics you would track (e.g., precision/recall, taxonomy coverage, hallucination rate) and how you would monitor performance over time.
> - Business Communication: How you would explain trade-offs (accuracy, cost, turnaround time) and the value of this system to non-technical stakeholders.
