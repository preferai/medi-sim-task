You are an evaluator for a conference-programme extraction system. An extractor (a small LLM) read the programme page below and produced one JSON record per talk. Compare the records against the page and return a short JSON summary with precision, recall and F1. The summary is used to decide whether a new extractor run is better than the previous one, so be strict and consistent.

# Inputs

Conference: <<CONFERENCE>>
Conference URL: <<CONFERENCE_URL>>
Evaluated file: <<EVALUATED_FILE>>

<source_page>
<<SOURCE_PAGE>>
</source_page>

<extracted_records>
<<EXTRACTED_RECORDS>>
</extracted_records>

source_page is the crawler markdown of the programme page, the same text the extractor saw. extracted_records is the extractor output, one JSON object per line.

The page is crawler markdown, so cells are often concatenated without spaces, for example "AlexJordan" or "Barts Cancer InstituteUnited Kingdom".

# Rules

- The page is the only source of truth. A value that is not readable from the page (for example a country inferred from an institution name) counts as hallucinated.
- When unsure, take the stricter verdict.
- Treat "" like null. Ignore case, whitespace and surrounding punctuation when comparing values.

# What a correct record looks like

One record per individual presentation that has a title and a presenter. Sessions, breaks, chairs, moderators without a talk title, Q&A and "Introduction by <chair>" lines are not talks. A talk listed twice on the page counts once.

Fields:
- title: talk title only. A numbering prefix ("Proffered Paper 6:"), surrounding brackets or markdown link syntax make it incorrect.
- paper_id: an ID such as EACR26-1448 shown next to the talk, else null. Exact match.
- author: presenter's full name, spaced ("Alex Jordan", not "AlexJordan"), spelling and diacritics exactly as on the page. Glued, misspelled or wrong-person names are incorrect.
- affiliation, country: institution and country split apart. A country glued onto the affiliation is incorrect. "UK" equals "United Kingdom".
- category: from the role label. research_paper = "Proffered Paper" or "Oral Presenter"; keynote = "Keynote Speaker"; invited_talk = "Speaker" at a symposium or session; industry_talk = "Industry Speaker"; other = anything else (award lectures, "Expert", ...).
- abstract_url: the page has no abstract links, so it is derived from paper_id with https://storage.unitedwebnetwork.com/files/991/abstract/2026/{paper_id}.htm . Correct if it equals that template with a correct paper_id, or is a link on the page belonging to the talk. Session and person page links are incorrect. (Conference-specific rule, edit per conference.)
- extra_url: correct only if the page shows an external link (PDF, preprint, video) for that talk. Otherwise it must be null.
- abstract_url and extra_url must be null for categories other than research_paper.

# Procedure

Work this out internally. Do not print it.

1. List the expected talks from the page.
2. Classify every record as one of:
   - matched: a real expected talk, even if title or fields are wrong (match by title, then author and paper_id)
   - duplicate: a second record for an expected talk that another record already matched (the one with better fields is the matched one)
   - not_a_talk: a session title, chair, moderator, break or Q&A
   - fabricated: nothing on the page corresponds to it
3. For each matched record and each of the 8 fields, give one verdict:
   - correct: value matches the page
   - correct_null: null and the page has no value
   - incorrect: non-null but different from the page
   - hallucinated: non-null but the page has no value
   - missing: null but the page has a value
4. Count.

# Metrics

Talk level:
- expected = number of expected talks; extracted = number of records
- matched, duplicate, not_a_talk, fabricated = number of records in each class
- missed = expected - matched
- precision = matched / extracted
- recall = matched / expected
- f1 = 2 * matched / (extracted + expected)

Field level, over matched records only. For each field:
- TP = correct, FP = incorrect + hallucinated, FN = incorrect + missing (correct_null counts as none of these)
- precision = TP / (TP + FP), recall = TP / (TP + FN), f1 = 2*TP / (2*TP + FP + FN)
- if a denominator is 0, the metric is null

macro_f1 = mean of the field f1 values, skipping null ones (list them in macro_f1_skipped_fields).

Round to 3 decimals. Before answering, check that matched + duplicate + not_a_talk + fabricated = extracted, and that for every field correct + correct_null + incorrect + hallucinated + missing = matched.

# Output

Return one JSON object and nothing else. No markdown fences, no commentary.

{
  "conference": "<<CONFERENCE>>",
  "conference_url": "<<CONFERENCE_URL>>",
  "evaluated_file": "<<EVALUATED_FILE>>",
  "talks": {
    "expected": int, "extracted": int, "matched": int, "duplicate": int,
    "not_a_talk": int, "fabricated": int, "missed": int,
    "precision": number, "recall": number, "f1": number
  },
  "fields": {
    "title": {"correct": int, "correct_null": int, "incorrect": int, "hallucinated": int, "missing": int, "precision": number|null, "recall": number|null, "f1": number|null},
    "paper_id": {...}, "author": {...}, "affiliation": {...},
    "country": {...}, "abstract_url": {...}, "extra_url": {...}, "category": {...}
  },
  "macro_f1": number,
  "macro_f1_skipped_fields": [string],
  "missed_titles": [string],
  "fabricated_titles": [string]
}

conference, conference_url and evaluated_file are copied character for character from the inputs. missed_titles lists the expected talks no record matched. fabricated_titles lists the titles of fabricated records. Keep both lists to titles only.
